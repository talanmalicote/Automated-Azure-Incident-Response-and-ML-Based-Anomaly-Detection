# Python-SIEM-Monitoring-Platform

## Short Intro

This project is a Security Information and Event Management (SIEM) platform built using Python and PostgreSQL to ingest and analyze security event logs for threat detection and incident investigation. It simulates a SOC pipeline by processing authentication, network, and web logs applying SQL-based detection rules, and generating security alerts based on certain behavioral thresholds. To add visualization, I made a dashboard in Grafana to see time-series charts, 

## Technologies
- Python
- PostgreSQL
- SQL
- Docker
- Grafana
- Pandas
- NumPy
